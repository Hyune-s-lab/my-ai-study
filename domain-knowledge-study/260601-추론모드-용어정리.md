# 추론(Reasoning) 모드 — 프로바이더별 용어 정리

## 1. 요약

### 1.1 TL;DR

- 같은 개념(모델이 답 내기 전에 숨겨진 "생각 토큰"으로 단계별 추론)을 프로바이더마다 다른 이름·파라미터로 부른다.
- **Anthropic = Extended Thinking(띵킹)**, **OpenAI = Reasoning(리즈닝)**, **Google Gemini = Thinking(Deep Think)**.
- 제미나이는 앤트로픽과 같은 단어("Thinking")를 쓰지만 **세대별로 파라미터가 다르다**: 2.5는 `thinking_budget`(토큰 수), 3.x는 `thinking_level`(등급).
- 셋 다 "얼마나 깊이 생각할지"를 다이얼로 조절한다. 깊을수록 정확도↑, 지연·비용↑.
- thinking 토큰은 대부분 숨겨지고 요약만 반환된다(DeepSeek 예외). 하지만 **과금 대상**이라 비용 계산 시 빠뜨리기 쉽다.

### 1.2 한 줄 정의

| 용어 | 한 줄 정의 |
|---|---|
| `thinking / reasoning token` | 모델이 최종 답 전에 내부적으로 단계별 추론을 적는, 보통 사용자에게 숨겨지는 토큰 |
| `reasoning model` | 이런 사고 과정을 학습·강화한 모델 계열 (OpenAI o-시리즈, Claude/Gemini의 thinking 변형 등) |
| `effort / budget / level` | "얼마나 오래·깊게 생각할지"를 조절하는 손잡이 (프로바이더마다 형태가 다름) |

## 2. 프로바이더별 비교표

| 프로바이더 | 부르는 이름 | API 손잡이 | 비고 |
|---|---|---|---|
| **Anthropic** | **Extended Thinking** (확장된 사고) | `thinking` + effort 파라미터 (Opus 4.7 / Sonnet 4.6) | 예전 `budget_tokens` 방식은 deprecated -> adaptive thinking + effort로 전환 |
| **OpenAI** | **Reasoning** (추론) | `reasoning_effort` / `reasoning.effort` (`none` ~ `xhigh`) | o-시리즈에서 시작. Responses API에서 `reasoning.summary`로 요약 노출 |
| **Google Gemini** | **Thinking** (Deep Think) | 2.5: `thinking_budget` (0~32,768 토큰) / 3.x: `thinking_level` (MINIMAL·LOW·MEDIUM·HIGH) | 세대별 파라미터가 달라 섞으면 에러 |
| **xAI Grok** | reasoning | `reasoning_mode` | |
| **DeepSeek** | CoT (Chain-of-Thought) | 내부 CoT 토글 | V4-Flash는 **실제 thinking 토큰을 노출**하는 드문 케이스 |

## 3. 프로바이더별 상세

### 3.1 Anthropic — Extended Thinking

- 이름: **Extended Thinking**(확장된 사고). 한국에서 흔히 "띵킹 모드"라 부른다.
- 과거에는 `thinking: { type: "enabled", budget_tokens: N }`로 사고 토큰 예산을 직접 지정.
- 현재(Opus 4.6/4.7 · Sonnet 4.6)는 **adaptive thinking + effort 파라미터**로 전환. 모델이 문제 난이도에 따라 사고량을 적응적으로 조절.
- 사고 과정은 응답에서 별도 블록으로 제공될 수 있음.

#### adaptive thinking vs budget_tokens — 어떻게 다른가

같은 "얼마나 생각할지"를 다루지만 **제어 주체**가 다르다.

| 구분 | `budget_tokens` (구방식, deprecated) | `adaptive thinking` + `effort` (현재 권장) |
|---|---|---|
| 제어 방식 | 개발자가 사고 토큰 **상한을 숫자로 고정** (`budget_tokens: 8000`) | 개발자는 `effort`(low/medium/high)로 **성향만** 지정 |
| 사고량 결정 | 매 요청 동일하게 고정 예산 안에서 사고 | 모델이 **요청 난이도를 평가**해 쓸지/얼마나 쓸지 스스로 결정 |
| 쉬운 요청 | 그래도 예산만큼 사고할 수 있어 낭비 가능 | 사고가 **선택적** — 간단하면 거의 안 함 (비용↓, 지연↓) |
| 설정 형태 | `thinking: { type: "enabled", budget_tokens: N }` | `thinking: { type: "adaptive" }` + `effort: "high"` |

동작 요약:
- **adaptive 모드에선 thinking이 "선택"이다.** Claude가 요청 복잡도를 보고 extended thinking을 쓸지, 쓴다면 얼마나 쓸지 알아서 정한다.
- `effort` 기본값은 **high** — 품질이 속도·비용보다 중요한 복잡한 추론/분석/난이도 높은 코딩에 적합. `medium`은 토큰을 아끼면서 준수한 성능을 내는 균형점.
- **Opus 4.7부터는 항상 adaptive reasoning을 사용**한다. 고정 budget 모드 자체가 적용되지 않는다.
- 실무 의미: 고정 예산처럼 "비용 상한을 토큰 수로 못박는" 통제는 약해지는 대신, 쉬운 요청에서 자동으로 사고를 줄여 **평균 비용·지연을 낮추는** 방향이다. 비용 예측이 중요한 워크로드라면 effort 단계와 max_tokens로 간접 관리한다.

### 3.2 OpenAI — Reasoning

- 이름: **Reasoning**(추론). reasoning model이라 부른다.
- 손잡이: `reasoning_effort` (Chat Completions) / `reasoning.effort` (Responses). 값은 `none`부터 `xhigh`까지의 등급.
- Responses API에서는 `reasoning.summary`로 사고 과정의 **요약**을 받을 수 있음 (원문 토큰은 비공개).
- 사고 토큰은 출력 토큰으로 과금됨.

### 3.3 Google Gemini — Thinking / Deep Think

- 이름: **Thinking** (고난도 변형은 **Deep Think**).
- ⚠️ **세대별 파라미터가 다르다** — 가장 흔한 실수 포인트:
  - **Gemini 2.5** (Pro/Flash/Flash-Lite): `thinking_budget` — 사고에 쓸 토큰 수를 0~32,768로 직접 지정. `0`이면 사고 비활성화(가장 빠르고 저렴). Google 권장 시작값은 8,192, 어려운 수학/코딩은 16,384~32,768.
  - **Gemini 3.x**: `thinking_level` — `MINIMAL`·`LOW`·`MEDIUM`·`HIGH` 등급으로 지정 (3 Pro는 MINIMAL 제외).
  - 2.5 모델에 `thinking_level`을 주거나, 3.x에 구식 방식을 섞으면 에러 발생.
- 사고 토큰은 input 가격으로 과금되며 기본적으로 응답에 노출되지 않음.

## 4. 실무 공통 패턴

- **다이얼 조절**: 셋 다 "얼마나 깊이 생각할지"를 조절. 깊을수록 정확도↑, 지연·비용↑.
- **비공개 사고**: thinking 토큰은 대부분 숨겨지고 요약만 반환 (DeepSeek 예외).
- **숨은 과금**: thinking 토큰도 과금 대상. 응답 본문에 안 보여도 비용은 나간다 -> 비용 추정 시 반드시 포함.
- **게이트웨이 설계 시사점**: LLM gateway를 만든다면 프로바이더별로 다른 이 손잡이들을 **공통 추상화**(예: `effort: low|medium|high`)로 매핑하고, 내부에서 각 API 형태로 변환하는 어댑터 레이어가 필요하다.

## 5. 빠른 매핑 치트시트

```
"생각 깊이 조절"을 원할 때 어디를 만지나?

Anthropic   -> thinking + effort
OpenAI      -> reasoning_effort  (none ~ xhigh)
Gemini 2.5  -> thinking_budget   (0 ~ 32768 토큰)
Gemini 3.x  -> thinking_level    (MINIMAL/LOW/MEDIUM/HIGH)
xAI Grok    -> reasoning_mode
DeepSeek    -> 내부 CoT 토글
```
