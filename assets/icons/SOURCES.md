# 공용 아이콘 자산

저장소의 모든 문서와 다이어그램은 이 폴더의 자산을 재사용한다.
기술 제품은 Tech Stack Icons를 우선하고, 없을 때 TechIcons(Devicon)를 쓴다.
사람·일반 서버처럼 제품 로고가 아닌 역할은 Flaticon 무료 아이콘을 사용한다.
